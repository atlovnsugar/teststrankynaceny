METHODOLOGY

Sources, refresh and limitations

The app is designed around primary statistical sources wherever practical. Secondary Czech regional data is clearly labelled as such.

OPERATIONS

How the data stays current

Weekly fuel: a GitHub Actions job downloads the latest European Commission Weekly Oil Bulletin workbook, extracts the 27 EU member states, and commits the normalized JSON files back to the repository.

Gas: the same refresh job reads Eurostat's nrg_pc_202 API for D2 household prices with I_TAX and EUR/KWh.

Crude: the job refreshes the daily EIA Brent Europe series through FRED.

Czech regions: the job attempts the public regional feed advertised by cenaPHM.cz. If that secondary feed changes shape or becomes unavailable, the previous successful snapshot is preserved rather than replaced by guessed data.

Maps: NUTS geometry is served by the European Commission GISCO service. The UI also keeps a table fallback so data remains usable when a map endpoint is blocked by a browser/network policy.

Built as a static GitHub Pages app. No database or paid backend required.
Prices are source-labelled; check the source date before making time-sensitive decisions.
